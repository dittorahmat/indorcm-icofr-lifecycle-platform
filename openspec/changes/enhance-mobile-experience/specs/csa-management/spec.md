## ADDED Requirements

### Requirement: Responsive Presentation Mode
The system SHALL provide both full-width desktop table visualization and adaptive mobile card-stack visualization for CSA activity monitoring and execution.

#### Scenario: Mobile viewport detection
- **WHEN** user accesses CSA monitoring or workbench on a screen width below 768px
- **THEN** the system SHALL render assessment items in card-stack format
- **AND** maintain full sorting, filtering, and detail expansion capabilities
