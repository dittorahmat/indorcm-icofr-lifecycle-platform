## MODIFIED Requirements

### Requirement: Global Notification Center
The system SHALL provide a global notification center accessible via a bell icon in the main layout header or sidebar.

#### Scenario: Unread notifications badge
- **WHEN** user has 5 unread notifications
- **THEN** the bell icon SHALL display a red badge with the number "5"

#### Scenario: Notification Bell in Sidebar
- **WHEN** the user is on any page with the app sidebar
- **THEN** a Notification Bell icon SHALL be visible in the sidebar to provide real-time alerts
