## MODIFIED Requirements

### Requirement: Centralized Execution Navigation
The system SHALL provide a unified entry point to all compliance activities from the sub-process list.

#### Scenario: Open sub-process hub
- **WHEN** user clicks on a sub-process name in the BPM Page
- **THEN** system SHALL open the Execution Hub Modal with all relevant tabs (Worksheet, Sampling, CSA, RCM Matrix)
