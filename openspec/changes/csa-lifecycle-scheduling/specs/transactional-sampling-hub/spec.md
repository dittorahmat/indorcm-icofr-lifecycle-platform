## ADDED Requirements

### Requirement: Integrated sampling from GL
The system SHALL provide a "Detail Transaksi" tab that lists all relevant transaction records for the current sub-process.

#### Scenario: Select transactions as samples
- **WHEN** user checks multiple transaction rows in the "Detail Transaksi" tab and clicks "Add as Samples"
- **THEN** system SHALL automatically populate those rows into the "CSA Assessment" tab
