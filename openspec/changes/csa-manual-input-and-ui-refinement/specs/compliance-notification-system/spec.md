## MODIFIED Requirements

### Requirement: Global Notification Center
The system SHALL provide a global notification center accessible via a bell icon in the main layout (sidebar or header).

#### Scenario: Unread notifications badge
- **WHEN** user has unread notifications
- **THEN** the bell icon SHALL display a red badge with the count or "9+" if exceeding 9.

#### Scenario: Sidebar Integration
- **WHEN** the user views the application sidebar
- **THEN** a notification bell with a real-time unread count SHALL be visible to allow quick access to recent alerts.
