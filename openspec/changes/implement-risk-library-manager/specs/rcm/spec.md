## ADDED Requirements

### Requirement: Standardized Risk Selection in Control Editor
The system SHALL provide a "Risk Library Lookup" button within the Control Editor to allow users to select from standardized risks.

#### Scenario: User selects a risk from the library
- **WHEN** User clicks "Lookup Risk Library" and selects a risk entry
- **THEN** the risk description and suggested assertions SHALL be automatically populated into the Control Editor form
