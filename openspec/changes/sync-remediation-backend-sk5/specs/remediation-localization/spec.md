## ADDED Requirements

### Requirement: Multi-language Support for Remediation
The system SHALL support English (EN) and Indonesian (ID) for all labels, placeholders, and status names within the Remediation module.

#### Scenario: Switch Language on Deficiency Board
- **WHEN** user changes application language from English to Indonesian
- **THEN** all remediation field labels (e.g., "Related Function" to "Fungsi Terkait") and statuses (e.g., "Draft" to "Draft") SHALL update accordingly
