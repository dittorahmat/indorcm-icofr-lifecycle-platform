## ADDED Requirements

### Requirement: Print PDF Functionality
The system SHALL provide a "Print / Export PDF" button on the `VerificationDesignPage` that triggers the browser's native print dialog.

#### Scenario: Clicking Print
- **WHEN** the user clicks the "Print / Export PDF" button
- **THEN** the browser print dialog opens, displaying the table formatted for landscape printing, with sidebars and navigation hidden.
