## MODIFIED Requirements

### Requirement: CSA Assessment Workspace
The system SHALL provide a comprehensive workspace for performing Control Self-Assessments, now including formal procedural documentation and archive tracking.

#### Scenario: Documenting test procedures
- **WHEN** the user is in the CSA Assessment tab
- **THEN** they SHALL find new input fields for "Test Procedures" and "Archive Location"
- **AND** these fields SHALL be saved during draft and final sign-off
