## MODIFIED Requirements

### Requirement: Scoping Parameter Matrix
The system SHALL provide a matrix for identifying significant accounts and locations. The Scoping Parameter Identification panel SHALL be positioned on the **RIGHT** side of the view, and the main Scoping Grid/Tabs SHALL be positioned on the **LEFT** side.

#### Scenario: Scoping layout arrangement
- **WHEN** user views the Scoping page
- **THEN** the Scoping Matrix/Grid MUST appear to the left of the Parameter Identification panel.
