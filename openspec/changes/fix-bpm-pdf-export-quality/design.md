## Context

The `BPMEditor` uses React Flow to render business process maps. The current "Document View" mode provides a static preview of the diagram intended for printing. However, browser `window.print()` fails to capture the complexity of the React Flow canvas (SVG lines, dynamic node positioning, and specific CSS background colors).

## Goals / Non-Goals

**Goals:**
- Consistent PDF output across Chrome, Edge, and Firefox.
- Retain all node styling, colors, and edge connections.
- Support long/wide diagrams by auto-calculating optimal zoom/scaling.
- Provide a clear UX (loading indicator) while the snapshot is being generated.

**Non-Goals:**
- Creating a server-side PDF generation service (Client-side generation is sufficient for current volume).
- Enabling text selection in the resulting PDF (Image-based PDF is acceptable).

## Decisions

### 1. Snapshot Library: `html-to-image`
- **Choice**: `html-to-image` (specifically `toPng`).
- **Rationale**: It is more actively maintained and has better support for SVG and nested CSS transforms than `dom-to-image`.
- **Alternative**: `html2canvas`. Rejected because it often struggles with complex SVG line rendering (edges in React Flow).

### 2. PDF Engine: `jsPDF`
- **Choice**: `jsPDF` (already in `package.json`).
- **Rationale**: Industry standard for client-side PDF generation. We will insert the PNG generated by `html-to-image` into a `jsPDF` instance.

### 3. Execution Flow
- User clicks "Print / Export PDF".
- Show "Generating PDF..." toast/overlay.
- Set `isExporting` state to `true` to trigger `useUnsavedChanges` protection.
- Programmatically trigger `fitView` on the hidden `ReactFlow` instance in Document View.
- Capture the `.react-flow__viewport` element using `html-to-image`.
- Determine diagram aspect ratio vs. A4 page.
- Create `jsPDF` (landscape or portrait based on ratio).
- `doc.addImage(...)` and save.
- Call `POST /api/bpm-exports` to log the event.
- Trigger a success notification in the `NotificationBell`.
- Set `isExporting` to `false`.

### 4. Database Schema: `bpm_exports`
- `id`: UUID (Primary Key)
- `organizationId`: References `organization.id`
- `userId`: References `user.id`
- `diagramId`: References `bpm_diagrams.id`
- `filename`: Text
- `createdAt`: Timestamp

## Risks / Trade-offs

- **[Risk] High Memory Usage for Massive Diagrams** → **Mitigation**: Use `quality: 0.95` and cap resolution if necessary.
- **[Risk] Timing Issues** → **Mitigation**: Add a small delay (100-200ms) after `fitView` before taking the snapshot to ensure layout is settled.
- **[Risk] Font Rendering** → **Mitigation**: Ensure fonts are pre-loaded or use system fonts for reliability.
